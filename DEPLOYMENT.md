# Reference deployment: FastAPI + Docker + Streamlit

A lightweight scoring service for the **TF-IDF + Logistic Regression** model. It was chosen for production over RoBERTa-base because it scores an e-mail in about **0.4 ms** (vs about 14 ms) at a small accuracy cost (test F1 0.985 vs 0.994) and needs no GPU (see Section 23 of the study).

These files are generated by Section 24 of the training notebook. The model files are not stored in Git; create them by running the pipeline, which writes them to `working/deployment/`.

| File | Purpose |
|---|---|
| `app.py` | FastAPI service with `GET /health` and `POST /predict` |
| `streamlit_app.py` | Simple web demo that scores a pasted e-mail |
| `Dockerfile`, `requirements-api.txt` | Container image for the API |
| `deploy_config.example.json` | Decision threshold and model name |

## Run

```bash
# copy tfidf_vectorizer.joblib and logreg_model.joblib from the notebook run into the repository root
cp deploy_config.example.json deploy_config.json

docker build -t phishing-api .
docker run -p 8000:8000 phishing-api

curl -X POST localhost:8000/predict -H "Content-Type: application/json" \
     -d '{"text": "Urgent: verify your account now at http://example.com"}'

# or the demo UI
pip install streamlit scikit-learn joblib && streamlit run streamlit_app.py
```

## Threshold note

Set `threshold` to a value tuned on **this model's** validation probabilities. The notebook's cost-optimal threshold (0.010) was tuned for RoBERTa-base, whose probabilities sit almost entirely at 0 or 1; applied to Logistic Regression it would flag far too many legitimate e-mails. `0.5` is a safe default until a model-specific threshold is tuned.
